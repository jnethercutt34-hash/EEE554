2. Module 1: Probability Foundations

Events and Set Operations

The sample space S contains every possible outcome. An event A is a subset of S.

Core rules
P(S)=1,   P(∅)=0,   0≤P(A)≤1
P(Ac)=1−P(A)
P(A∪B)=P(A)+P(B)−P(A∩B)
A∩B=∅   ⇒   P(A∪B)=P(A)+P(B)

Conditional Probability, Bayes Rule, and Total Probability

P(A|B)=P(A∩B)/P(B),   P(A∩B)=P(A|B)P(B)
P(A|B)=P(B|A)P(A)/P(B)
P(A)=ΣiP(A|Bi)P(Bi)
  1. For a posterior probability such as P(X=i | Y=j), write Bayes rule first.
  2. Use total probability for the denominator P(Y=j) if needed.
  3. For a joint probability, use P(X=i,Y=j)=P(Y=j|X=i)P(X=i).
Independence:
P(A∩B)=P(A)P(B)   ⇔   P(A|B)=P(A)
Mutually exclusive nonzero-probability events are not independent.

Binary Communication Error Pattern

  1. Make the four joint probabilities from the priors and channel conditionals.
  2. Marginalize across transmitted symbols to find P(Y=0) and P(Y=1).
  3. Apply Bayes for the probability of a transmission given a received symbol.
  4. Sum the two incorrect joint events.
Pe=P(Y=0|X=1)P(X=1)+P(Y=1|X=0)P(X=0)

3. Module 2: PMF, PDF, and CDF

TypeKey factProbability method
DiscreteFinite or countably infinite values; P(X=x) may be nonzeroUse PMF and sums
ContinuousValues on a real interval; P(X=x)=0Use PDF and integrals
MixedContinuous parts plus point massesUse density plus CDF jumps
FX(x)=P(X≤x)
CDF facts
  1. FX(−∞)=0 and FX(∞)=1.
  2. The CDF never decreases.
  3. P(x1<X≤x2)=FX(x2)−FX(x1)
  4. For a discrete or mixed RV, a CDF jump is point probability: P(X=x0)=FX(x0)−FX(x0−)
Discrete:   P(X=xi)=pX(xi),   ΣpX(xi)=1
Continuous:   fX(x)=dFX(x)/dx,   P(a≤X≤b)=∫abfX(x)dx
A PDF value is not a probability. For a continuous RV, probability is the area under the PDF.

4. Common RV Classes

RVModelMean and variance
Bernoulli(p)P(X=1)=p; P(X=0)=1−pE[X]=p; Var(X)=p(1−p)
Binomial(N,p)P(X=k)=(N choose k)pk(1−p)N−kE[X]=Np; Var(X)=Np(1−p)
Poisson(λ)P(X=k)=e−λλk/k!E[X]=λ; Var(X)=λ
Uniform(a,b)f(x)=1/(b−a), a≤x≤bE[X]=(a+b)/2; Var(X)=(b−a)²/12
Exponential(λ)f(x)=λe−λxu(x)E[X]=1/λ; Var(X)=1/λ²
Gaussian(μ,σ²)f(x)=(1/√(2πσ²))e−(x−μ)²/(2σ²)E[X]=μ; Var(X)=σ²
Rayleigh(σ)f(x)=x/σ² · e−x²/(2σ²)u(x)Support x≥0; tail is e−x²/(2σ²)
Z=(X−μ)/σ,   Z~N(0,1),   P(X>x)=Q((x−μ)/σ)
Q(x)=(1/√(2π))∫x∞e−t²/2dt
Binomial → Poisson limit: as M→∞, p→0, with Mp=λ held fixed, the Binomial(M,p) PMF converges to the Poisson(λ) PMF. Use this whenever a problem describes a rare event over a large number of independent opportunities.

5. Expectation, Variance, and Characteristic Functions

Discrete: E[X]=ΣxiP(X=xi)
Continuous: E[X]=∫xfX(x)dx,   E[g(X)]=∫g(x)fX(x)dx
E[aX+b]=aE[X]+b
Var(X)=E[X²]−(E[X])²
Var(X+b)=Var(X),   Var(aX+b)=a²Var(X)
ΦX(ω)=E[ejωX],   E[Xn]=ΦX(n)(0)/jn
Chebyshev:   Pr(|X−μX|>γ) ≤ σX²/γ²
Fast check: scaling by 2 multiplies variance by 4, not 2. Chebyshev needs only mean and variance — no distribution assumed — so it is typically a much looser bound than a Gaussian tail estimate.

6. Transformations of Random Variables

For Y=g(X), first find the output support. Then decide whether the transformation is one-to-one, many-to-one, or maps an interval to one output value.

  1. Map SX through g to obtain SY.
  2. For a complicated transformation, derive FY(y)=P(g(X)≤y) first.
  3. Use the inverse/Jacobian rule for a monotonic one-to-one mapping.
  4. Use all valid roots for a many-to-one mapping.
  5. Include a point mass when an interval of input values is clipped to one output value.

One-to-One Transformation

fY(y)=fX(g−1(y)) · |d[g−1(y)]/dy|
Y=aX+b:   fY(y)=(1/|a|)fX((y−b)/a)
Pattern: If X~U(0,2) and Y=3X+1, then Y~U(1,7) and fY(y)=1/6,   1≤y≤7

Many-to-One Transformation

fY(y)=Σvalid roots xifX(xi)/|g'(xi)|
Y=|X|:   fY(y)=fX(y)+fX(−y),   y≥0
For Y=X², include both roots, +√y and −√y, when both are in the support of X.

Mixed RV from Clipping

Y=min(X,xmax):   P(Y=xmax)=P(X≥xmax)=1−FX(xmax)

7. Final Review Checklist

  1. Can you identify joint, marginal, conditional, and independent probabilities?
  2. Can you apply Bayes rule after finding a total-probability denominator?
  3. Can you create a CDF, derive a PDF, and identify a CDF jump?
  4. Can you distinguish PMF sums from PDF integrals?
  5. Can you identify the listed standard distributions and their mean/variance, and recognize when Binomial reduces to Poisson (M large, p small, Mp=λ fixed)?
  6. Can you standardize a Gaussian and use the Q-function?
  7. Can you find E[X], E[g(X)], Var(X), and Var(aX+b)?
  8. Can you apply Chebyshev's inequality when only a mean and variance are given?
  9. Can you handle support, Jacobian, multiple roots, and clipping in transformations?
Study order: Probability rules and Bayes first; CDF/PMF/PDF next; then moments and Gaussian/Q-function; finish with transformations because they combine most Module 2 skills.
