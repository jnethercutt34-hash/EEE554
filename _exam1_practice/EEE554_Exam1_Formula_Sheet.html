Notation

S=sample space ∅=impossible event Ac=not A A∪B=A or B (or both) A∩B=AB=A and B A⊂B=A subset of B P(A|B)="prob of A given B" ~="is distributed as" u(x)=unit step δ(x)=Dirac delta / unit impulse Σ=sum (discrete) ∫=integral (continuous)

Read the notation aloud:

P(A|B) = "prob. of A given B" — P(B|A) = "prob. of B given A" (NOT the same thing)

P(A∩B) = "prob. A and B both occur" — P(A∪B) = "prob. A or B or both occur"

The event after the bar is what you already know happened. In P(A|B), start inside B, then ask what fraction of B is also A — that's why P(B) is in the denominator.

Axioms & Set Rules

Axioms of probability: P(A) ≥ 0;   P(S) = 1;   P(∅) = 0
Axiom 3 (mutually exclusive): A∩B=∅ ⇒ P(A∪B)=P(A)+P(B)
Complement rule: P(Ac) = 1 − P(A)
Complement rule (conditional form): P(Ac|B) = 1 − P(A|B)  (holds for any fixed B — e.g. P(Y=0|X=1)=1−P(Y=1|X=1))
Union / inclusion–exclusion rule: P(A∪B) = P(A)+P(B)−P(A∩B)
Subset property: if B⊂A: P(A|B)=1;   if A⊂B: P(A|B)=P(A)/P(B) ≥ P(A)

Conditional Prob., Bayes, Total Prob.

Conditional probability (definition): P(A|B) = P(A∩B)/P(B), P(B)≠0
Multiplication rule (chain rule): P(A∩B) = P(A|B)P(B) = P(B|A)P(A)
Bayes' theorem (Bayes' rule): P(A|B) = P(B|A)P(A) / P(B)
Partition (definition): {Bi}: Bi∩Bj=∅ (i≠j), ∪Bi=S
Law of total probability: P(A) = Σi P(A|Bi)P(Bi)
Bayes' theorem (generalized, with partition): P(Bi|A) = P(A|Bi)P(Bi) / ΣjP(A|Bj)P(Bj)
Probability of error (binary channel): Pe=P(Y=0|X=1)P(X=1)+P(Y=1|X=0)P(X=0)

Independence

Independence (definition): A,B indep. ⟺ P(A∩B)=P(A)P(B) ⟺ P(A|B)=P(A)
Independence property: indep. ⇒ Ac,B also indep.; Ac,Bc also indep.
Mutual independence: B1,…,BN indep. ⇒ P(∩Bi) = Π P(Bi)

mutually exclusive (nonzero-prob.) events are NEVER independent

CDF (discrete & continuous)

CDF (definition): FX(x) = P(X≤x); FX(−∞)=0, FX(∞)=1, nondecreasing
Interval probability from CDF: P(x1<X≤x2) = FX(x2) − FX(x1)
Tail (complement) probability: P(X>x) = 1 − FX(x)
Point-mass probability (CDF jump): P(X=x0) = FX(x0) − FX(x0−)

PMF (discrete X)

PMF (definition): fX(x) = Σi P(X=xi) δ(x−xi)

"Find the PMF" = list P(X=xi) for every value xi. Given a CDF, each PMF value IS the size of the CDF jump at that xi (see Point-mass/CDF jump formula above) — that's the whole method.

Probability from PMF: P(x1≤X≤x2) = ∫x1x2 fX(x)dx = Σ P(X=xi) in range
PMF normalization: Σall i P(X=xi) = 1

PDF (continuous X)

PDF (definition): fX(x) = dFX(x)/dx ≥ 0; FX(x) = ∫−∞x fX(t)dt
Probability from PDF / normalization: P(a≤X≤b) = ∫ab fX(x)dx; ∫−∞∞ fX(x)dx = 1

"Verify a valid PDF/PMF" = check BOTH conditions: (1) f≥0 everywhere (nonneg., above) AND (2) total = 1 (normalization, above). Either one alone is not enough.

Zero point-probability (continuous RV): P(X=x0) = 0

mixed RV: CDF jump at xi ⇒ PDF gets +P(X=xi)δ(x−xi)

Expectation, Variance, Moments

Mean / expected value: E[X] = ΣxiP(X=xi)  or  ∫xfX(x)dx
Expected value of a function (LOTUS): E[g(X)] = Σg(xi)P(X=xi)  or  ∫g(x)fX(x)dx
Linearity of expectation: E[aX+b] = aE[X]+b  (a,b constants)
Variance (computational formula): Var(X) = E[X²]−(E[X])² = E[(X−μX)²]
Variance scaling properties: Var(b)=0; Var(X+b)=Var(X); Var(aX+b)=a²Var(X)
Moments (definition): nth moment E[Xn]; nth central moment E[(X−μX)n]
Characteristic function (definition): ΦX(ω)=E[ejωX]=∫ejωxfX(x)dx
Moment from characteristic function: E[Xn] = (1/jn) · dnΦX(ω)/dωn |ω=0
Chebyshev's inequality: P(|X−μX|>γ) ≤ σX²/γ²
Sample mean & sample variance (estimators): μ̂=1/M·Σxi; σ̂²=1/M·Σxi²−μ̂²

Gaussian & Q-function

Gaussian (normal) PDF: X~N(μ,σ²): fX(x) = 1/√(2πσ²) · e−(x−μ)²/(2σ²)
Standardization (Z-score): Z=(X−μ)/σ ~ N(0,1); FX(x)=Φ((x−μ)/σ)=1−Q((x−μ)/σ)
Gaussian tail probability / Q-function (definition): P(X>x) = Q((x−μ)/σ); Q(x) = 1/√(2π) ∫x∞ e−t²/2dt
Q-function properties: Q(0)=0.5; Q(−x)=1−Q(x); Q(x)=0.5·erfc(x/√2)
Sum of independent Gaussians: iid Xi~N(μ,σ²), i=1..M ⇒ Y=ΣXi ~ N(Mμ, Mσ²)

Recognize the story (for "which RV is this?" problems):

Bernoulli=1 trial, success/fail Binomial=# successes in N indep. trials Poisson=# arrivals/events in fixed interval, constant rate Uniform=every value in interval equally likely Exponential=waiting time to next event, constant rate Gaussian=sum/combo of many small indep. effects Rayleigh=magnitude of a 2-D vector w/ iid zero-mean Gaussian components (e.g. fading-channel amplitude, wind speed from (vx,vy))
Binomial coefficient ("N choose k"): C(N,k) = N!/(k!(N−k)!)
Binomial → Poisson limit: M→∞, p→0, Mp=λ fixed

Transformations Y = g(X)

One-to-one (monotonic, invertible):

CDF transformation: FY(y) = FX(g−1(y))
PDF transformation (Jacobian / inverse-function formula): fY(y) = fX(g−1(y)) · |d[g−1(y)]/dy| = fX(g−1(y)) / |g′(g−1(y))|
Affine transformation (Y=aX+b): fY(y) = (1/|a|) fX((y−b)/a)

Many-to-one (N roots xi=g−1(y)):

Many-to-one formula (sum over roots): fY(y) = Σi=1N fX(xi) / |g′(xi)|
Absolute-value transformation (Y=|X|): fY(y) = fX(y)+fX(−y), y≥0
Squaring transformation (Y=X²): roots ±√y, g′(x)=2x  ⇒  fY(y)=[fX(√y)+fX(−√y)]/(2√y), y>0

General / clipping (mixed RV):

General transformation procedure: find SY=g(SX) first; FY(y)=P(X∈Ry), Ry={x: g(x)≤y}
Clipping / saturation formula: Y=min(X,xmax): P(Y=xmax) = P(X≥xmax) = 1−FX(xmax−)
Mixed-RV rule: g(x) constant on an interval ⇒ Y has a point mass (CDF jump) there
