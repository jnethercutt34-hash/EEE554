Section A — Probability Foundations

Problem 1
 Region A (y ≤ 4−x)     Region B (x ≤ 2)     A∩B (cross-hatched, the trapezoid (0,0)-(2,0)-(2,2)-(0,4))
Area(S) = 4×4 = 16. Probabilities are area(event)/16.
A = points with y ≤ 4−x: this is the triangle below the line from (0,4) to (4,0), i.e. vertices (0,0),(4,0),(0,4).
Area(A) = ½·4·4 = 8  ⇒  Pr(A) = 8/16 = 0.5
B = points with x ≤ 2: a 2×4 rectangle.
Area(B) = 8  ⇒  Pr(B) = 0.5
A∩B: for 0≤x≤2, y ranges from 0 to 4−x (the line 4−x is always ≥2 on this interval, so B doesn't cut the triangle further — the intersection is the left portion of the triangle).
Area(A∩B) = ∫₀² (4−x) dx = [4x − x²/2]₀² = 8 − 2 = 6  ⇒  Pr(A∩B) = 6/16 = 0.375
Pr(A|B) = Pr(A∩B)/Pr(B) = 0.375/0.5 = 0.75
Independence check: Pr(A)·Pr(B) = 0.5×0.5 = 0.25 ≠ 0.375 = Pr(A∩B)  ⇒  not independent.
Problem 2
Let D = defective, F = flagged. Pr(D)=0.02, Pr(Dc)=0.98, Pr(F|D)=0.95, Pr(F|Dc)=0.03.
Total probability:
Pr(F) = Pr(F|D)Pr(D) + Pr(F|Dc)Pr(Dc) = 0.95(0.02) + 0.03(0.98) = 0.019 + 0.0294 = 0.0484
Bayes' rule:
Pr(D|F) = Pr(F|D)Pr(D)/Pr(F) = 0.019/0.0484 = ≈0.393
Even with a fairly accurate sensor, most flags are false alarms — this is the same structure as the classic rare-disease test problem: a low base rate dominates the result.
Problem 3
36 equally likely outcomes for two dice.
Pr(A) = Pr(sum=7) = 6/36 = 1/6 (outcomes: (1,6),(2,5),(3,4),(4,3),(5,2),(6,1))
Pr(B) = Pr(first die=4) = 6/36 = 1/6
A∩B = "first die is 4 and sum is 7" ⇒ second die must be 3 ⇒ exactly 1 outcome: (4,3).
Pr(A∩B) = 1/36
Check: Pr(A)Pr(B) = (1/6)(1/6) = 1/36 = Pr(A∩B)  ⇒  independent.
This is a good example that independence is not always intuitive — knowing the first die is 4 does narrow down which second-die value gives a 7, but it doesn't change the overall probability of getting a 7.
Problem 4
Let M1, M2, M3 be the machine-source events, Pr(M1)=0.30, Pr(M2)=0.45, Pr(M3)=0.25 (a partition of S).
Defect rates: Pr(D|M1)=0.04, Pr(D|M2)=0.02, Pr(D|M3)=0.05.
Total probability:
Pr(D) = 0.30(0.04) + 0.45(0.02) + 0.25(0.05) = 0.012 + 0.009 + 0.0125 = 0.0335
Bayes' rule:
Pr(M2|D) = Pr(D|M2)Pr(M2)/Pr(D) = 0.009/0.0335 = ≈0.269

Pr(X=0)=0.6, Pr(X=1)=0.4, Pr(Y=1|X=1)=0.85 ⇒ Pr(Y=0|X=1)=0.15, Pr(Y=0|X=0)=0.92 ⇒ Pr(Y=1|X=0)=0.08.

Section B — PMF, PDF, CDF

Problem 6
Each PMF value is the size of the CDF jump at that point:
Pr(X=−1) = 0.15 − 0 = 0.15
Pr(X=0) = 0.45 − 0.15 = 0.30
Pr(X=1) = 0.75 − 0.45 = 0.30
Pr(X=2) = 1 − 0.75 = 0.25
(Check: 0.15+0.30+0.30+0.25 = 1.00 ✓)
Pr(−1≤X≤1) = Pr(X=−1)+Pr(X=0)+Pr(X=1) = 0.15+0.30+0.30 = 0.75
  (cross-check with CDF formula: FX(1) − FX(−1) + Pr(X=−1) = 0.75 − 0.15 + 0.15 = 0.75 ✓)
Pr(X>0), method 1 (sum PMF): Pr(X=1)+Pr(X=2) = 0.30+0.25 = 0.55
Pr(X>0), method 2 (via CDF): 1 − FX(0) = 1 − 0.45 = 0.55 — both agree.
Problem 7
Valid PDF check: ∫₀∞ 3e−3x dx = [−e−3x]₀∞ = 0−(−1) = 1 ✓ and fX(x)≥0. Valid.
CDF: FX(x) = ∫₀x 3e−3t dt = 1 − e−3x for x≥0 (0 otherwise). This is Exponential(λ=3).
Pr(0.2<X≤0.5) = FX(0.5) − FX(0.2) = (1−e−1.5) − (1−e−0.6) = e−0.6 − e−1.5 = 0.5488 − 0.2231 = ≈0.3257
Pr(X>1) = 1 − FX(1) = e−3 = ≈0.0498
Problem 8
fX(x) = 1/10 for −5≤x≤5.
Pr(Y=3) = Pr(X>3) = ∫₃⁵ (1/10) dx = 2/10 = 0.2
Pr(Y=−3) = Pr(X<−3) = ∫−5−3 (1/10) dx = 2/10 = 0.2
For −3<y<3, the mapping is the identity (Y=X, unclipped), so fY(y) = fX(y) = 1/10.
Total-probability check: continuous part = ∫−3³ (1/10) dy = 6/10 = 0.6; point masses = 0.2+0.2 = 0.4; sum = 1.0 ✓
CDF shape: FY(y)=0 for y<−3, jumps immediately to 0.2 at y=−3 (all the clipped mass below −3 lands exactly at y=−3), rises linearly with slope 1/10 from 0.2 at y=−3 to 0.8 at y=3⁻, then jumps by 0.2 to reach 1 at y=3, and stays at 1 for y>3. This is a classic mixed RV: continuous in the middle, two point masses at the clip limits.
Open circle = value approached but not attained; filled circle = actual CDF value (right-continuous, as required)
Problem 9
(a) Independent arrivals at a constant average rate over a fixed interval ⇒ Poisson(λ=0.5)
(b) Equally likely over a fixed interval ⇒ Uniform(0,10)
(c) Magnitude of a 2-D vector with independent, equal-variance zero-mean Gaussian components ⇒ Rayleigh(σ) (this is exactly the "fading channel magnitude" story from the notes)
(d) Count of successes in a fixed number of independent trials ⇒ Binomial(N=20, p=0.3)

Problem 10
E[X] = (−1)(0.15) + (0)(0.30) + (1)(0.30) + (2)(0.25) = −0.15+0+0.30+0.50 = 0.65
E[X²] = (1)(0.15) + (0)(0.30) + (1)(0.30) + (4)(0.25) = 0.15+0+0.30+1.00 = 1.45

Problem 11
X~N(2,4) ⇒ μ=2, σ²=4, σ=2.
Pr(X>6): z=(6−2)/2=2 ⇒ Pr(X>6) = Q(2) = ≈0.0228
Pr(−2<X<2): z₁=(−2−2)/2=−2, z₂=(2−2)/2=0.
Pr(−2<X<2) = Φ(0) − Φ(−2) = [1−Q(0)] − Q(2) = 0.5 − 0.0228 = ≈0.4772
  (used Φ(0)=0.5 and Φ(−2)=Q(2) since Φ(−z)=Q(z))
Find x₀ with Pr(X>x₀)=0.01: need Q((x₀−2)/2)=0.01 ⇒ (x₀−2)/2 ≈ 2.33 ⇒ x₀ = 2+4.66 = ≈6.66
Problem 12
X~U(2,6): fX(x)=1/4 for 2≤x≤6; E[X]=(2+6)/2=4; Var(X)=(6−2)²/12=16/12=4/3.
g(x)=−2x+10 has g′(x)=−2≠0 everywhere ⇒ strictly monotonic (decreasing) ⇒ one-to-one.
Endpoints: x=2 ⇒ y=6; x=6 ⇒ y=−2 (order flips because g is decreasing) ⇒ SY = (−2, 6).
fY(y) = (1/|a|) fX((y−b)/a) = (1/2)(1/4) = 1/8, for −2<y<6 (this is Y~U(−2,6), interval length 8, and indeed 1/8 matches a uniform density on that length).
(i) Directly: E[Y] = (−2+6)/2 = 2; Var(Y) = (6−(−2))²/12 = 64/12 = 16/3.
(ii) Via properties: E[Y] = −2E[X]+10 = −2(4)+10 = 2; Var(Y) = (−2)²Var(X) = 4(4/3) = 16/3.
Both methods agree: E[Y]=2, Var(Y)=16/3.
Problem 13
ΦX(ω) = λ(λ−jω)−1. Let u = λ−jω, so du/dω = −j.
Φ′(ω) = λ(−1)u−2(−j) = jλ u−2. At ω=0, u=λ: Φ′(0) = jλ/λ² = j/λ.
E[X] = (1/j)Φ′(0) = (1/j)(j/λ) = 1/λ
Φ″(ω) = jλ(−2)u−3(−j) = 2j²λ u−3 = −2λ u−3. At ω=0: Φ″(0) = −2λ/λ³ = −2/λ².
E[X²] = (1/j²)Φ″(0) = (1/(−1))(−2/λ²) = 2/λ²
Var(X) = E[X²] − (E[X])² = 2/λ² − 1/λ² = 1/λ²
  These match the tabulated exponential results in the lecture notes (Table 11.1) — a good way to check your differentiation.

Section D — Bonus: Gap-Fill Practice

Problem 14 — Binomial → Poisson
λ = Mp = 200(0.015) = 3. Approximating PMF: Pr(X=k) ≈ e−33k/k!, k=0,1,2,…
Pr(X=3) ≈ e−3(3³)/3! = e−3(27/6) = 4.5 e−3 = 4.5(0.04979) = ≈0.2240
Pr(X≤1) = Pr(X=0)+Pr(X=1) = e−3 + 3e−3 = 4e−3 = 4(0.04979) = ≈0.1991
The approximation is reasonable because M=200 is large, p=0.015 is small, and the product λ=Mp=3 is a moderate, fixed value — exactly the regime (M→∞, p→0, Mp=λ) where the binomial PMF converges to the Poisson PMF (Homework 2, Problem 1).
Problem 15 — Many-to-one transformation
X ~ N(0,4): σ²=4, so fX(x) = 1/√(8π) · e−x²/8.
Y = X² ⇒ for any y>0, SY = (0,∞), and there are two roots: x₁=√y and x₂=−√y (for y≤0, fY(y)=0 since a square can't be negative).
Many-to-one formula: fY(y) = Σᵢ fX(xᵢ)/|g′(xᵢ)|, where g′(x)=2x so |g′(x₁)|=|g′(x₂)|=2√y.
fY(y) = fX(√y)/(2√y) + fX(−√y)/(2√y). Since fX is symmetric (fX(√y)=fX(−√y)), this is
fY(y) = fX(√y)/√y = [1/√(8π)]e−y/8 / √y = e−y/8 / √(8πy),   y > 0
  (this is the general result fY(y) = 1/√(2πσ²y) · e−y/(2σ²) for X~N(0,σ²), Y=X² — a scaled chi-square/exponential-type density)
fY(1) = e−1/8/√(8π) = 0.8825/5.0133 = ≈0.1761
Problem 16 — Chebyshev inequality
Chebyshev: Pr(|X−μ| > γ) ≤ σ²/γ².
(1) γ=12: bound = 9/12² = 9/144 = 0.0625 (i.e., Chebyshev guarantees Pr(|X−50|>12) is at most 6.25%, using only the mean and variance — no distribution assumed).
(2) Solve σ²/γ² = 0.05 ⇒ γ² = 9/0.05 = 180 ⇒ γ = √180 ≈ 13.42
(3) If X were Gaussian, ~95% of the probability lies within 2σ = 2(3) = 6 of the mean, i.e. Pr(|X−50|>6) ≈ 0.05 — a much tighter bound than Chebyshev's γ≈13.42. This is expected: Chebyshev makes no assumption about the shape of the distribution, so it must cover the worst case over all distributions with that mean and variance, which makes it noticeably looser than a bound that assumes a specific (Gaussian) shape.
