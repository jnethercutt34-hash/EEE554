Section A — Probability Foundations (Module 1) [40 pts]

Problem 18 pts
The sample space is S = {(x,y): 0 ≤ x ≤ 4, 0 ≤ y ≤ 4}, and outcomes are equally likely (probability of an event is proportional to its area). Define events A = {(x,y): y ≤ 4 − x} and B = {(x,y): x ≤ 2}.
  1. (2 pts) Sketch the regions A and B in the (x,y)-plane.
  2. (3 pts) Find Pr(A), Pr(B), and Pr(A∩B).
  3. (2 pts) Find Pr(A | B).
  4. (1 pt) Are A and B independent? Justify with numbers, not just intuition.
 
Problem 28 pts
An inline sensor on a factory line flags parts it believes are defective. Only 2% of parts are actually defective. If a part is defective, the sensor flags it with probability 0.95. If a part is not defective, the sensor still (incorrectly) flags it with probability 0.03.
  1. (3 pts) Find the probability that a randomly chosen part gets flagged.
  2. (5 pts) Given that a part is flagged, find the probability it is actually defective.
 
Problem 36 pts
Two fair six-sided dice are rolled. Let A = "the sum of the two dice is 7" and B = "the first die shows a 4."
  1. (4 pts) Compute Pr(A), Pr(B), and Pr(A∩B) directly by counting outcomes.
  2. (2 pts) Are A and B independent? Show the check numerically — don't just guess.
 
Problem 48 pts
A plant has three machines producing items in proportions 30%, 45%, and 25% (machines 1, 2, 3). Their defect rates are 4%, 2%, and 5%, respectively.
  1. (4 pts) Find the overall probability that a randomly selected item is defective.
  2. (4 pts) Given that an item is defective, find the probability it came from machine 2.
 
Problem 510 pts
A binary transmitter sends X ∈ {0,1} with Pr(X=0) = 0.6 and Pr(X=1) = 0.4. The channel is characterized by Pr(Y=1|X=1) = 0.85 and Pr(Y=0|X=0) = 0.92.
  1. (4 pts) Build the table of all four joint probabilities Pr(X=i, Y=j).
  2. (2 pts) Find Pr(Y=1).
  3. (2 pts) Find Pr(X=1 | Y=1).
  4. (2 pts) Find the probability of error, Pe.
 

Section B — PMF, PDF, CDF (Module 2) [30 pts]

Problem 68 pts
A discrete RV X, representing an inspection grade, takes values in {−1, 0, 1, 2} with CDF
FX(x) = 0 for x<−1;   0.15 for −1≤x<0;   0.45 for 0≤x<1;   0.75 for 1≤x<2;   1 for x≥2
  1. (3 pts) Find the PMF of X (list Pr(X=xi) for each value).
  2. (2 pts) Find Pr(−1 ≤ X ≤ 1).
  3. (3 pts) Find Pr(X > 0) two different ways and confirm they agree.
 
Problem 78 pts
A sensor's lifetime X (in years) has PDF fX(x) = 3e−3x for x ≥ 0 (and 0 otherwise).
  1. (2 pts) Verify this is a valid PDF.
  2. (2 pts) Find the CDF FX(x).
  3. (2 pts) Find Pr(0.2 < X ≤ 0.5).
  4. (2 pts) Find the probability the sensor lasts more than 1 year.
 
Problem 88 pts
A signal amplitude X ~ U(−5, 5) passes through a limiter, producing Y: Y = X for −3 ≤ X ≤ 3; Y = 3 for X > 3; Y = −3 for X < −3.
  1. (3 pts) Find Pr(Y = 3) and Pr(Y = −3).
  2. (2 pts) Find the PDF of Y for −3 < y < 3.
  3. (3 pts) Confirm the total probability (point masses + continuous part) equals 1, and describe the shape of the CDF of Y.
 
Problem 96 pts
For each scenario, name the standard RV class (Bernoulli, Binomial, Poisson, Uniform, Exponential, Gaussian, or Rayleigh) and give its parameter(s). No probability calculation needed.
  1. Number of typos on a page, when typos occur independently at an average rate of 0.5 per page.
  2. The exact minute (past the hour) a bus arrives, equally likely anywhere in a 10-minute window.
  3. The magnitude of a 2-D wind velocity vector whose components are independent, zero-mean Gaussians with equal variance σ².
  4. The number of heads in 20 flips of a coin with Pr(heads) = 0.3.
 

Section C — Moments, Gaussian RVs, Transformations (Module 2) [30 pts]

Problem 108 pts
Using the RV X from Problem 6 (PMF: Pr(X=−1)=0.15, Pr(X=0)=0.30, Pr(X=1)=0.30, Pr(X=2)=0.25):
  1. (2 pts) Find E[X].
  2. (2 pts) Find E[X²].
  3. (2 pts) Find Var(X).
  4. (2 pts) If Y = 2X − 3, find E[Y] and Var(Y) using the properties of expectation — do not recompute from a new PMF.
 
Problem 118 pts
An amplifier's output noise voltage is X ~ N(2, 4) (mean 2, variance 4).
  1. (3 pts) Express Pr(X > 6) in terms of the Q-function and evaluate it.
  2. (3 pts) Find Pr(−2 < X < 2).
  3. (2 pts) Find x0 such that Pr(X > x0) = 0.01. (You may use Q(2.33) ≈ 0.01.)
 
Problem 128 pts
Let X ~ U(2, 6) and define Y = g(X) = −2X + 10.
  1. (2 pts) Find the support of Y.
  2. (2 pts) Explain why g is one-to-one on this support, then find fY(y) using the one-to-one transformation formula.
  3. (4 pts) Find E[Y] and Var(Y) two ways: (i) directly from fY(y), and (ii) using linearity/scaling properties applied to E[X] and Var(X). Confirm they match.
 
Problem 136 pts
The characteristic function of an exponential RV X with rate λ is ΦX(ω) = λ/(λ − jω).
  1. (3 pts) Use ΦX(ω) to find E[X].
  2. (3 pts) Use ΦX(ω) to find E[X²], then Var(X).
 

Section D — Bonus: Gap-Fill Practice [not scored in the 100]

These three cover topics that are explicitly in the reading list and Homework 2 but were under-represented in Sections A–C: the Poisson-as-limit-of-Binomial connection, many-to-one (squaring) transformations, and the Chebyshev inequality.
Problem 14 — Binomial → Poissonbonus
A batch of 200 components has an independent per-component defect rate of 1.5%. Let X = number of defective components, exactly Binomial(M=200, p=0.015).
  1. Using the limit M→∞, p→0 with Mp=λ held fixed, find λ for this batch and write the approximating Poisson PMF.
  2. Using the Poisson approximation, estimate Pr(X=3) and Pr(X≤1).
  3. In one sentence, explain why the Poisson approximation is reasonable here.
 
Problem 15 — Many-to-one transformationbonus
Let X ~ N(0, 4) (mean 0, variance 4) and Y = X².
  1. Find the support of Y, and state how many roots x map to a given y > 0.
  2. Derive fY(y) using the many-to-one transformation formula (sum over both roots).
  3. Evaluate fY(1).
 
Problem 16 — Chebyshev inequalitybonus
A measurement X has unknown distribution but known mean μ = 50 and variance σ² = 9.
  1. Use Chebyshev's inequality to bound Pr(|X−50| > 12).
  2. Find a value γ such that Chebyshev guarantees Pr(|X−50| > γ) ≤ 0.05.
  3. Compare γ from part 2 to what you'd get by assuming X is Gaussian and using the "~95% within 2σ" rule. Which bound is tighter, and why is that expected?
