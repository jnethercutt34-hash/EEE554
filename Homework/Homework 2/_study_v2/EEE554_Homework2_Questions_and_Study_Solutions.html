1. Binomial-to-Poisson Limit

Set p = λ/n in the binomial PMF and take the limit with λ fixed.

P[X = k] = (n choose k)pk(1 − p)n−k
P[X = k] → e−λλk / k!,   k = 0, 1, 2, ...
This is the Poisson(λ) PMF.

2. Parity Transformation of a Poisson RV

Sum the Poisson probabilities over all even values and all odd values.

P[Y = 1] = (1 + e−2λ) / 2
P[Y = −1] = (1 − e−2λ) / 2

3. Best Constant Estimate of a Bernoulli RV

Minimize the mean-square error over a constant estimate.

X̂ = E[X] = p
MSE = E[(X − X̂)2] = p(1 − p)
p = 1/2,   MSEmax = 1/4
The error is largest when both outcomes are equally likely.

4. Binomial Characteristic Function

ΦX(ω) = [1 − p + pejω]n
E[X] = np,   Var(X) = np(1 − p)
p = λ/n:   ΦX(ω) → eλ(ejω − 1)
The limiting characteristic function is Poisson(λ).

5. Q-Function Identity

Q(x) = (1 / √(2π)) ∫x∞ e−t²/2 dt = P[N > x]

6. Affine Transformation of a Gaussian RV

For X ~ N(0,1) and Y = 2X + μ:

fY(y) = (1 / √(8π))e−(y − μ)²/8
Y ~ N(μ, 4)

7. Squared Standard Normal RV

fY(y) = e−y/2 / √(2πy),   y > 0
fY(y) = 0,   y ≤ 0
Y ~ χ²1

8. Clipped Rayleigh RV

Let Y = min(X, xmax).

fY(y) = fX(y),   0 ≤ y < xmax
P[Y = xmax] = 1 − FX(xmax) = e−xmax²/(2σ²)

9. Exponential Characteristic Function and n-th Moment

ΦX(ω) = λ / (λ − jω)
E[Xn] = n! / λn

10. Rare Events and Importance Sampling

(a) Gaussian sampling

P[X > 8] = Q(5) ≈ 2.87 × 10−7
N ≈ 10 / Q(5) ≈ 3.5 × 107 samples

(b) Shifted exponential comparison RV

P[Y > 8] = e−5 ≈ 6.74 × 10−3
N ≈ 10 / e−5 ≈ 1.48 × 103 samples

(c) Importance sampling

P[X > 8] = EY[I(Y > 8)fX(Y) / fY(Y)]
h(y) = I(y > 8) · (1 / √(2π))e−(y − 3)²/2 + (y − 3)
