1. Binomial-to-Poisson Limit

Question. The binomial PMF is P[X = k] = (n choose k)pk(1 − p)n−kfor k = 0, 1, ... , n. Consider n → ∞ and p → 0, while λ = np remains constant. Express the limit in terms of λ. What PMF is it?
  1. Since λ = np, substitute p = λ/n.
  2. For fixed k, the first factor approaches (n choose k)(λ/n)k → λk/k!
  3. The remaining factor approaches (1 − λ/n)n−k → e−λ
  4. Multiply the two limiting factors.
Final result.
P[X = k] → e−λλk/k!,   k = 0, 1, 2, ...
This is the Poisson(λ) PMF.

2. Parity Transformation of a Poisson RV

Question. Let X be Poisson with parameter λ. Define Y = 1 if X is even and Y = −1 if X is odd. Find the PMF of Y.
  1. For Y = 1, sum the Poisson PMF over X = 0, 2, 4, ....
  2. For Y = −1, sum the PMF over X = 1, 3, 5, ....
  3. Use the even and odd exponential series, or equivalently use eλ = cosh(λ) + sinh(λ)
Final result.
P[Y = 1] = (1 + e−2λ)/2
P[Y = −1] = (1 − e−2λ)/2

3. Best Constant Estimate of a Bernoulli RV

Question. Predict a Bernoulli random variable X with parameter p, where 0 ≤ p ≤ 1, using its best constant estimate X̂. (a) Find X̂. (b) Find the mean-square error. (c) When is the error maximum, and why?
  1. Let the constant estimate be a, and minimize J(a) = E[(X − a)2]
  2. Expanding and differentiating gives dJ/da = −2E[X] + 2a = 0
  3. Therefore a = E[X] = p.
  4. For a Bernoulli RV, X² = X, so its variance and minimum MSE are p(1 − p).
  5. The parabola p(1 − p) is largest at p = 1/2.
Final result.
X̂ = p,   MSE = p(1 − p),   MSEmax = 1/4 at p = 1/2

4. Binomial Characteristic Function

Question. For a binomial RV X: (a) calculate its characteristic function; (b) determine its expected value and variance from the characteristic function; and (c) show it becomes the Poisson characteristic function as n → ∞, p → 0, with λ = np fixed.
  1. Start with ΦX(ω) = E[ejωX] = Σ ejωkP[X = k]
  2. Insert the binomial PMF and apply the binomial theorem.
  3. Use E[X] = Φ'X(0)/j and E[X²] = −Φ''X(0), then calculate variance.
  4. Set p = λ/n and use the exponential limit (1 + z/n)n → ez
Final result.
ΦX(ω) = [1 − p + pejω]n
E[X] = np,   Var(X) = np(1 − p)
ΦX(ω) → eλ(ejω − 1)

5. Q-Function Identity

Question. For a PSK system, the probability of error uses the Q-function. If N ~ N(0,1), prove Q(x) = P[N > x].
  1. Write the definition of the Q-function.
  2. Write the standard normal PDF.
  3. The integral of the PDF from x to infinity is, by definition, the upper-tail probability.
Final result.
Q(x) = (1/√(2π)) ∫x∞ e−t²/2dt = P[N > x]

6. Affine Transformation of a Gaussian RV

Question. Let X ~ N(0,1) and use the affine transformation Y = 2X + μ. Prove Y ~ N(μ, 4).
  1. Solve for X: X = (Y − μ)/2
  2. Apply the change-of-variables rule with the Jacobian magnitude 1/2.
  3. Substitute the standard normal PDF and simplify.
  4. The coefficient of (y − μ)² identifies variance 4.
Final result.
fY(y) = (1/√(8π))e−(y − μ)²/8,   Y ~ N(μ, 4)

7. Squared Standard Normal RV

Question. Let X ~ N(0,1) and Y = X². Find fY(y).
  1. The support is y ≥ 0.
  2. For y > 0, solve x² = y to get the two inverse values x = √y and x = −√y.
  3. Apply the change-of-variables rule to both branches; each has derivative magnitude 2√y.
  4. Add the two equal normal-density contributions.
Final result.
fY(y) = e−y/2/√(2πy),   y > 0
fY(y) = 0,   y ≤ 0

8. Clipped Rayleigh RV

Question. Let X be Rayleigh. Define Y = X for 0 ≤ X < xmax and Y = xmax for X ≥ xmax. Find the distribution of Y.
  1. Below the clipping threshold, the transformation is the identity, so the continuous density remains the Rayleigh density.
  2. Every value of X at or above xmax maps to one value of Y.
  3. That tail probability becomes a discrete probability mass at xmax.
Final result.
fY(y) = fX(y),   0 ≤ y < xmax
P[Y = xmax] = 1 − FX(xmax) = e−xmax²/(2σ²)

9. Exponential Characteristic Function and n-th Moment

Question. Let X be exponential with rate λ. (a) Calculate ΦX(ω). (b) Calculate the n-th moment using the characteristic function.
  1. Start with the exponential PDF λe−λxu(x).
  2. Integrate ejωx times the PDF from 0 to infinity.
  3. For moments, use E[Xn] = ΦX(n)(0) / jn
  4. Differentiate the rational characteristic function n times and evaluate at zero.
Final result.
ΦX(ω) = λ/(λ − jω)
E[Xn] = n!/λn

10. Rare Events and Importance Sampling

Question. Let X ~ N(3,1). (a) Express P[X > 8] as an integral and estimate samples needed for 10 events. (b) For fY(y) = e−(y−3)u(y−3), find samples needed for 10 events Y > 8. (c) Express P[X > 8] using importance sampling and give the explicit weighting function.

(a) Gaussian sampling

  1. Standardize: (8 − 3)/1 = 5.
  2. Therefore the upper-tail probability is Q(5).
  3. The expected number of exceedances in N trials is NQ(5). Set this equal to 10.
P[X > 8] = Q(5) ≈ 2.87 × 10−7
N ≈ 10/Q(5) ≈ 3.5 × 107 samples

(b) Shifted exponential comparison RV

  1. For Y > 8, the excess over the shift is 8 − 3 = 5.
  2. The exponential tail is e−5.
  3. Set the expected number of successes N e−5 equal to 10.
P[Y > 8] = e−5 ≈ 6.74 × 10−3
N ≈ 10/e−5 ≈ 1.48 × 103 samples

(c) Importance sampling

  1. Write the target probability as an integral using the target Gaussian density fX.
  2. Multiply and divide the integrand by the proposal density fY.
  3. Recognize the resulting integral as an expectation under Y.
P[X > 8] = EY[I(Y > 8)fX(Y)/fY(Y)]
h(y) = I(y > 8) · (1/√(2π))e−(y − 3)²/2 + (y − 3)
